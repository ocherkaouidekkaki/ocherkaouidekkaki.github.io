# Research portfolio design preview

This preview is self-contained and has not replaced the live Jekyll homepage. Its source files are portfolio-preview/index.html, styles.css and site.js.

It contains research directions, selected projects, peer-reviewed papers, preprint links, conference contributions and biography. Publication search, filters, mobile navigation, and an illustrative nonlinear dynamical-system explorer work without a backend.

The demonstration x' = x(1-x)-u is pedagogical, not a numerical result from a research paper. Publication statuses and the biography should be approved before production release.

To publish the eventual redesign, first approve the visual direction, then migrate the preview into the website root or Jekyll layouts. GitHub Pages currently uses the master branch; this branch changes no live page.
